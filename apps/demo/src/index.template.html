Surgesim in your browser

The same engine that runs in Node, simulating in a Web Worker on this page. Drag components onto the diagram or edit the JSON, then run it; nothing leaves your machine.

Paste kubectl get deploy,svc,hpa -o yaml output and an overlay with the traffic, service times and calls the manifests cannot describe. Import turns them into a model (Deployments become pools, HPAs autoscalers), then it runs and replays on the diagram.
